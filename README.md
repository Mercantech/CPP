# CPP

C++ til H3 og H5 — interaktiv læringsplatform.

**Live:** [cpp.mercantec.tech](https://cpp.mercantec.tech)

## Lokalt

```bash
cd web
npm install
npm run dev
```

Eller med Docker:

```bash
docker compose -f docker-compose.yml -f docker-compose.local.yml up --build
```

## Indhold

- **Historie** — C → C++ → arv til C# m.fl.
- **H3** — Struktureret C++ til Arduino (funktioner, datatyper, scope, filopdeling, kodestandarder)
- **H5** — Kommer snart
