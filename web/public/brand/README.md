# C++-mærke

`cplusplus.svg` er den uændrede officielle Simple Icons-fil for C++:
https://github.com/simple-icons/simple-icons/blob/develop/icons/cplusplus.svg

Hentet 20. oktober 2026. Simple Icons udgiver ikoner under CC0:
https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

UI'et viser det monokrome mærke lyst på mørk baggrund via CSS-filter.
De eksisterende historiske billeder og logoer ligger i `/history`.
